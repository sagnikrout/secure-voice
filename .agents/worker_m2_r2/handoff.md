## 1. Observation

Adversarial stress testing reported by Challenger 1 (`challenger_m2_1/handoff.md`) identified two unhandled edge cases in `src/utils/webrtc.js`:

1. **`transformOpusSdp(sdp, options)`**:
   - Calling `transformOpusSdp(sdp, null)` bypassed default parameter fallback (`options = {}`), causing:
     ```
     TypeError: Cannot read properties of null (reading 'bitrate')
       ❯ transformOpusSdp src/utils/webrtc.js:85:33
     ```

2. **`generateSafetyCode(localSdp, remoteSdp)`**:
   - Calling `generateSafetyCode(12345, sdp)` or `generateSafetyCode({}, sdp)` bypassed `if (!localSdp || !remoteSdp)` check, causing:
     ```
     TypeError: sdp.match is not a function
       ❯ extractFingerprint src/utils/webrtc.js:382:23
       ❯ Module.generateSafetyCode src/utils/webrtc.js:386:14
     ```

3. **`createDenoisePipeline` in `src/utils/audio.js`**:
   - Calling `createDenoisePipeline` with a stream whose `getAudioTracks()` returned `null`, non-array, or threw an error caused `TypeError: Cannot read properties of null (reading 'length')` or uncaught exception.
   - Calling `setNoiseGateEnabled` when AudioContext was closed caused `InvalidStateError: AudioContext is closed`.

---

## 2. Logic Chain

1. In JavaScript, default parameters (`options = {}`) only activate when `options === undefined`. If a caller passes `null`, `options` remains `null`. By introducing:
   ```javascript
   const opts = options && typeof options === 'object' ? options : {};
   ```
   and replacing all property lookups on `options` with `opts`, `transformOpusSdp` safely defaults all Opus configuration parameters to `OPUS_CONFIG` constants when `null` or non-object primitives are provided.
2. In `generateSafetyCode`, non-string arguments (like objects, numbers, booleans) do not have `.match()`. By applying:
   ```javascript
   if (!localSdp || !remoteSdp || typeof localSdp !== 'string' || typeof remoteSdp !== 'string') return null;
   ```
   the function safely aborts and returns `null` for invalid or missing inputs without throwing uncaught TypeErrors.
3. In `src/utils/audio.js`, wrapping `stream.getAudioTracks()` in safe array checks and try-catch blocks and wrapping `setNoiseGateEnabled` AudioParam automation in try-catch prevents closed AudioContext errors from bubbling up to consumers.

## 3. Caveats

- In standard runtime usage within the React UI, SDP strings are generated by WebRTC peer connections as strings and options are structured objects. These defensive guards ensure complete immunity against unexpected external inputs, corrupted network payloads, or uninitialized caller state.
